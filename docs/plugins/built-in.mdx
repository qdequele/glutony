---
title: Built-in plugins
description: Reference for every plugin compiled into the worker, with config keys and defaults
---

All built-in plugins live under `crates/plugins/<name>` and are registered by
`PluginRegistry::builtin()`. Config keys below go in the step's `config:`
block; every key is optional unless stated otherwise.

<Note>
Documents produced by extractors set `meta.source`, `meta.filename` and
`meta.mime` from the input blob, and derive ids from the sanitised filename
plus a page/row suffix (`report_pdf_p3`, `data_csv_r42`).

`csv_parser` additionally stores the 1-based row number in a `_row` field. The
parsers that decode to JSON first — `json_flattener`, `msgpack_parser`,
`avro_parser`, `parquet_parser` — deliberately do not: their generated id
already carries the index, and keeping the family uniform matters more than
matching CSV.
</Note>

## Extractors (bytes → documents)

### `pdf_extractor`

Text extraction from PDF (`pdf-extract`). Queue: `workers-general`.

| Key | Default | Description |
|---|---|---|
| `per_page` | `true` | One document per page (`meta.page` set); `false` → one document for the whole file. |
| `extract_images` | `false` | Reserved; accepted for forward compatibility. |

### `docx_extractor`

Word `.docx` (`docx-rs`). One document; paragraphs joined by `\n\n`, tables
rendered as tab-separated rows. No config keys.

### `xlsx_extractor`

Excel `.xlsx` / `.xls` (`calamine`).

| Key | Default | Description |
|---|---|---|
| `mode` | `"row"` | `row` → one document per row with header → cell pairs in `fields`, `meta.section` = sheet name. `sheet` → one document per sheet. |

### `html_extractor`

HTML (`scraper`). One document: `title` from `<title>`, `content` from
`<body>` minus `script`/`style`/`nav`/`footer`.

| Key | Default | Description |
|---|---|---|
| `extract_links` | `false` | Also collect `<a href>` targets into `fields.links`. |

### `markdown_extractor`

Markdown (`pulldown-cmark`).

| Key | Default | Description |
|---|---|---|
| `split_on_headings` | `true` | One document per top-level heading section, `meta.section` = heading text; `false` → one document. |

### `csv_parser`

CSV (`csv`). One document per row: header → `fields`, `content` = values
joined by a space.

| Key | Default | Description |
|---|---|---|
| `delimiter` | `","` | Single-character field delimiter. |
| `has_headers` | `true` | First row is the header. Without headers, fields are `col_0`, `col_1`, … |
| `id_column` | — | Column whose value becomes the document id. Otherwise `<filename>_r<row>`. |

### `json_flattener`

Accepts **bytes or documents**. Top-level array → one document per element;
object with a `documents`, `items` or `data` array → those; anything else →
one document. Nested objects are flattened to dotted keys (`a.b.c`) in
`fields`; `content` = concatenated string values.

| Key | Default | Description |
|---|---|---|
| `id_field` | `"id"` | Field used as document id; generated when missing. |

### `parquet_parser`

Apache Parquet (`parquet` + `arrow`). One document per row. The file's own
schema supplies the types, so nothing is guessed; nested structs flatten to
dotted keys and null cells are omitted. `columns` is pushed down into the
reader, so unselected columns are never decoded.

| Key | Default | Description |
|---|---|---|
| `id_field` | `"id"` | Flattened key used as document id. Otherwise `<filename>_r<row>`. |
| `content_fields` | every string leaf | Keys joined by a space into `content`. |
| `title_field` | — | Key mapped onto `title`. |
| `columns` | all | Columns to read, pushed down as a projection. An unknown name is an error. |
| `max_rows` | — | Stop after this many rows. |
| `batch_size` | `1024` | Rows decoded per record batch. |

### `avro_parser`

Avro object container files (`apache-avro`). One document per record. The
writer schema travels in the file, so logical types are resolved rather than
left as raw integers: `date` → `YYYY-MM-DD`, `timestamp-*` → RFC 3339,
`decimal` → a scaled string (a string, so no precision is lost), `uuid` and
`enum` → strings, `bytes`/`fixed` → base64. A union is unwrapped to the branch
that was actually written, so `["null","string"]` is just a string.

| Key | Default | Description |
|---|---|---|
| `id_field` | `"id"` | Flattened key used as document id. Otherwise `<filename>_r<row>`. |
| `content_fields` | every string leaf | Keys joined by a space into `content`. |
| `title_field` | — | Key mapped onto `title`. |
| `max_records` | — | Stop after this many records. |

### `msgpack_parser`

MessagePack (`rmpv`). Decodes to JSON values and then applies exactly the
`json_flattener` rules, so a single value follows the array / wrapper-object
selection and several concatenated values become one document each (the NDJSON
analog). `bin` becomes base64, non-string map keys are stringified, and the
standard timestamp extension becomes an RFC 3339 string.

<Note>
MessagePack has no magic bytes, so it cannot be sniffed from content. Upload it
with a `.msgpack`/`.mpk` filename or an explicit `application/vnd.msgpack`
content type, or route it with an explicit pipeline.
</Note>

| Key | Default | Description |
|---|---|---|
| `id_field` | `"id"` | Flattened key used as document id. Otherwise `<filename>_<index>`. |
| `content_fields` | every string leaf | Keys joined by a space into `content`. |
| `title_field` | — | Key mapped onto `title`. |
| `max_records` | — | Stop after this many documents. |

### `image_captioner`

Vision captioning through an OpenAI-compatible chat endpoint. One document
whose `content` is the caption. Queue: `workers-llm`. Requires `LLM_API_KEY`
on the worker (`LLM_BASE_URL`, `LLM_MODEL` optional).

| Key | Default | Description |
|---|---|---|
| `model` | `"gpt-4o-mini"` (or `LLM_MODEL`) | Vision-capable chat model. |
| `prompt` | built-in caption prompt | Instruction sent with the image. |
| `detail` | `"auto"` | Image detail hint (`low`, `high`, `auto`). |

## Transformers (documents → documents)

### `chunker`

Splits each document into overlapping chunks. Sets `meta.chunk_index`,
`meta.chunk_total`, `meta.parent_id`; chunk id = `<parent_id>_<index>`.
Accepts `documents` and `many`.

| Key | Default | Description |
|---|---|---|
| `strategy` | `"sentence"` | `sentence` (split on `.!?`), `fixed` (N chars), `paragraph` (split on `\n\n`). |
| `chunk_size` | `512` | Target chunk size in characters. |
| `overlap` | `64` | Characters shared between consecutive chunks. |
| `min_chunk_size` | `32` | Trailing fragments shorter than this are merged into the previous chunk. |

### `document_script`

Runs a sandboxed [rhai](https://rhai.rs) script once per document: rename fields,
drop them, compute new ones, promote a field into `title` or `content`, or filter
the document out. Accepts `documents` and `many`. Queue: `workers-general`.

| Key | Default | Description |
|---|---|---|
| `script` | *required* | The script, run once per document. |
| `on_error` | `"fail"` | What a per-document error does: `fail` the step, `skip` that document, or `keep` it untouched. |
| `max_ops` | `100000` | Rhai operations one document may use before the script is aborted. |
| `timeout_ms` | `1000` | Wall-clock milliseconds one document may use before the script is aborted. |

The document is bound as `doc`:

| Binding | Type | Writable |
|---|---|---|
| `doc.id` | string | yes — re-sanitised afterwards to stay Meilisearch-safe |
| `doc.title` | string or `()` | yes — set it to `()` to clear the title |
| `doc.content` | string | yes |
| `doc.fields` | map | yes |
| `doc.meta` | map | no — readable, but writes are discarded |

The script mutates `doc` in place. Returning `false` drops the document from the
output; any other result keeps it.

```yaml
- id: shape
  plugin: document_script
  config:
    script: |
      doc.fields.price = doc.fields.prix;     # rename
      doc.fields.remove("prix");              # drop
      doc.fields.total_ttc = doc.fields.price * doc.fields.qty * 1.2;
      doc.title = doc.fields.name;            # promote into title
      if doc.content.is_empty() { return false; }   # filter out
      true
    on_error: skip
```

<Warning>
  Rhai's string methods such as `trim()`, `to_upper()` and `pad()` take `&mut self`
  and return `()` — they edit the string in place rather than returning a copy. So
  `doc.content.trim() == ""` is always `false`. Write `doc.content.trim();` as its
  own statement, then test `doc.content.is_empty()`.
</Warning>

A script that does not compile fails the step immediately with a config error,
before any document is touched, whatever `on_error` says. A script that exceeds
`max_ops` or `timeout_ms` is aborted and treated as a per-document error.

Float arithmetic that produces NaN or an infinity is also a per-document error.
Rhai does not raise on `x / 0.0` the way it does on integer division by zero, and
JSON has no way to spell those values — without the check they would be indexed as
`null` and the job would report success.

**Sandbox.** Pipeline configs are tenant-authored, so the engine is built with
`no_module` (no `import`/`export`), `no_custom_syntax` and `no_time`; rhai has no
file, network or process API, so a script can only reach `doc`. Every run is
additionally bounded by the operation and wall-clock budgets above, and by fixed
caps on expression depth, call depth, and string, array and map sizes.

### `llm_enricher`

Calls an OpenAI-compatible `/chat/completions` endpoint with
`response_format: {type: json_object}` for each document and merges the JSON
reply into the document. Accepts `documents` and `many`; usually used with
`fan_out: "$.documents"`. Queue: `workers-llm`. Requires `LLM_API_KEY`.

| Key | Default | Description |
|---|---|---|
| `model` | `"gpt-4o-mini"` (or `LLM_MODEL`) | Chat model. |
| `prompt` | built-in extraction prompt | System instruction. The document content is the user message. Ask for JSON. |
| `max_concurrent` | `8` | Parallel requests inside one activity (`buffer_unordered`). |
| `temperature` | `0` | Sampling temperature. |
| `fields_to_merge` | all keys | Restrict which keys of the reply are merged into `fields`. |

Reply keys are merged into `fields`; `title` → `title`, `summary` →
`fields.summary`, `keywords` → `fields.keywords`, `language` → `meta.language`.

## Sink (documents → indexed)

### `meili_indexer`

The only plugin that talks to Meilisearch (`meilisearch-sdk`). Accepts
`documents` and `many`. Host, API key and index come from the `MeiliContext`
the workflow injects — never from env vars and never from your config.

| Key | Default | Description |
|---|---|---|
| `primary_key` | `"id"` | Primary key declared when creating the index. |
| `auto_create_index` | `true` | Create the index when it does not exist. |
| `batch_size` | `1000` | Documents per `addDocuments` request. |
| `wait_for_completion` | `true` | Wait for Meilisearch tasks before finishing the step. |

Returns `Indexed { index, document_count, task_uids }`.

## `pptx_extractor`

`Bytes → Documents`. Parses the OOXML zip directly with `zip` + `quick-xml`, so
there is no LibreOffice subprocess. Slide parts are ordered numerically, and the
title comes from the shape carrying a `title` / `ctrTitle` placeholder, falling
back to the slide's first non-empty line.

| Key | Default | Description |
|---|---|---|
| `per_slide` | `true` | One document per slide with `meta.page`, else one per deck. |
| `include_notes` | `true` | Speaker notes into `fields.notes`. |
| `notes_in_content` | `false` | Also append notes to `content`. |
| `skip_empty_slides` | `true` | Drop slides with no text and no notes. |
| `max_slides` | `null` | Stop after this many slides. |

Decompression is bounded at 64 MiB per part and 256 MiB per deck. Uploads come
from untrusted tenants and deflate reaches ~1000:1, so an unbounded read would
let a small crafted file exhaust a worker.

## `whisper_transcriber`

`Bytes → Documents`. Posts the audio to an OpenAI-compatible
`/audio/transcriptions` endpoint, so it works against OpenAI, Groq or a
self-hosted whisper.cpp / faster-whisper server. Reads `TRANSCRIBE_API_KEY`,
`TRANSCRIBE_BASE_URL` and `TRANSCRIBE_MODEL`, each falling back to the `LLM_*`
equivalent. Runs on the `workers-gpu` queue.

| Key | Default | Description |
|---|---|---|
| `model` | `whisper-1` | Overrides `TRANSCRIBE_MODEL`. |
| `language` | `null` | ISO-639-1 hint. |
| `prompt` | `null` | Biasing prompt for names and jargon. |
| `temperature` | `null` | Sampling temperature. |
| `segment_documents` | `false` | One document per segment with `fields.start` / `fields.end`, else one for the whole file. |
| `timeout_secs` | `600` | Per-request timeout. |
| `max_bytes` | `26214400` | Reject larger uploads (the OpenAI limit). |

## `video_audio_extractor`

`Bytes → Bytes`. Demuxes and decodes with `symphonia`, resamples with `rubato`
and encodes 16 kHz mono 16-bit WAV with `hound` — 100% Rust, no ffmpeg. Feeds
`whisper_transcriber`. Runs on the `workers-gpu` queue.

| Key | Default | Description |
|---|---|---|
| `sample_rate` | `16000` | Output rate in Hz. |
| `mono` | `true` | Downmix all channels to one. |
| `max_duration_secs` | `null` | Stop decoding after this many seconds. |
| `track` | `null` | Decode this track id instead of the default audio track. |

Supported: MP4/MOV, MKV/WebM, OGG, WAV, FLAC, AIFF and CAF containers with
AAC-LC, MP1/MP2/MP3, ALAC, FLAC, Vorbis, PCM and ADPCM. AC-3, E-AC-3 and
Opus-in-MP4 are not decodable; those files fail with a message naming the codec,
and you can transcode them or register a gRPC plugin under the same name.

## Not compiled in

| Plugin | Queue | Status |
|---|---|---|
| `ocr` | `workers-gpu` | Provide as a gRPC plugin. |
| `s3_downloader` | `workers-io` | Reserved name; the worker already resolves `s3://` inputs itself. |

A step naming an unregistered plugin fails with
`plugin X is not registered on this worker; deploy a gRPC plugin`.
