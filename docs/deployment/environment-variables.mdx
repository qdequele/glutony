---
title: Environment variables
description: Every configuration knob of the gateway, workers and control plane
---

Configuration is environment-only. Variables are read once at startup
(`from_env()` constructors and `main.rs`); nothing is read from the environment
inside plugins or workflow code.

## Gateway (`meili-ingest-gateway`)

| Variable | Default | Description |
|---|---|---|
| `BIND` | `0.0.0.0:8080` | Listen address. |
| `TEMPORAL_URL` | `http://temporal-frontend:7233` | Temporal frontend. |
| `TEMPORAL_NAMESPACE` | `default` | Temporal namespace. |
| `CONTROL_PLANE_URL` | `http://meili-control-plane:9000` | Internal control plane. |
| `MEILI_URL` | — | Standalone fallback Meilisearch host (used when no `X-Meili-Host` and the request carries no tenant). |
| `MEILI_API_KEY` | — | Standalone fallback API key (used when no `X-Meili-Api-Key` / bearer and the request carries no tenant). |
| `DEFAULT_INDEX` | `documents` | Last resort of the index resolution chain. |
| `MAX_UPLOAD_MB` | `500` | Maximum request body; larger → `413`. |
| `ENVOY_TRUSTED_HEADER` | — | Shared secret. When set, `X-Meili-*` headers are honoured only if `X-Meili-Envoy-Secret` matches. Unset = trust headers (dev mode, warned at startup). Required with `LAB_SERVICE_TOKEN` or `LAB_INSTANCE_*`. `CHANGE_ME` is refused at boot. |
| `WRITE_PREFLIGHT` | `false` | Before queueing a job, check the request's Meilisearch key can add documents to (and read) the target index; answer `401`/`403` instead of a job that fails at `meili_indexer`. Skipped for pipelines pinned to a connection. Side-effect free: see `crates/gateway/src/preflight.rs`. |
| `BLOB_STORE_URL` | `file://./blobs` | Where uploads above `INLINE_MAX_BYTES` are staged (`file://`, `s3://`, `gs://`, `az://`, `memory://`). Must be shared with workers. |
| `INLINE_MAX_BYTES` | `1048576` | Uploads up to this size travel inside the Temporal payload; larger ones are staged. |
| `RUST_LOG` | `info` | `tracing` filter, e.g. `info,meili_ingest=debug`. |
| `SOURCE_SECRET_KEY` | — | 32 bytes, base64 (`openssl rand -base64 32`). Seals [connection](/concepts/connections) keys and [source](/concepts/sources) credentials. Unset = `/connections` and `/sources` answer `501`. Must match the workers'. Rotating it makes stored secrets unreadable. |
| `MEILI_CONNECTION_HOSTS` | `public` | Where connections may point: `public` (https, public addresses only), `any`, or a comma list of `host[:port]`. |
| `LAB_SERVICE_TOKEN` | — | Bearer token the Meilisearch Lab console sends to the management routes, together with a required `X-Glutony-Tenant-Id`: the `CREDENTIAL=` given to `bin/rails lab:hosted_engine:create` (`openssl rand -hex 32`). Setting it closes open mode, and the gateway refuses to start unless `ENVOY_TRUSTED_HEADER` is also set. See [Meilisearch Lab](/deployment/meilisearch-lab). |
| `ADMIN_API_KEY` | — | Operator bearer key for the management routes; `X-Glutony-Tenant-Id` is optional (without it the caller acts on the global scope). Setting it closes open mode. Turning it on also requires a management token or a trusted edge tenant on `GET /jobs/{id}`; ingest clients that poll with only a Meilisearch key get 401. Never reuse it as the Lab credential. `CHANGE_ME` is refused at boot. |
| `SOURCE_FETCH_HOSTS` | `public` | Where sources **and `{"url": …}` ingest bodies** may fetch from; same syntax. Checked when a source is saved, and on every ingest URL (a forbidden one is a `422`, no job queued). `public` means `https` and public addresses only, so plain-`http` URLs need an allowlist entry or `any`. |
| `CONTROL_PLANE_TOKEN` | — | Bearer token presented on every control-plane call. Required when the control plane enforces it (production). `CHANGE_ME` is refused at boot. |
| `LAB_URL` / `LAB_INSTANCE_ID` / `LAB_INSTANCE_SECRET` | — | All three or none, and only with `ENVOY_TRUSTED_HEADER`. `LAB_URL` is a base URL (no path or query). Enables the identity check at boot (a 401, or credentials of another product, aborts boot) and the credit pre-check on ingest and manual source runs (`402` out of credits, `503` when the Lab cannot be asked). See [Meilisearch Lab](/deployment/meilisearch-lab). |

## Worker (`meili-ingest-worker`)

| Variable | Default | Description |
|---|---|---|
| `TEMPORAL_URL` | `http://temporal-frontend:7233` | Temporal frontend. |
| `TEMPORAL_NAMESPACE` | `default` | Temporal namespace. |
| `TASK_QUEUE` | `workers-general` | Queue this worker polls: `workers-general`, `workers-llm`, `workers-gpu`, `workers-io`. |
| `CONTROL_PLANE_URL` | — | Plugin manifests are published there at boot (`POST /internal/plugins`). Required for Meilisearch connections and scheduled sources, which the worker loads from it. |
| `CONTROL_PLANE_TOKEN` | — | Bearer token presented on every control-plane call. Required when the control plane enforces it (production). `CHANGE_ME` is refused at boot. |
| `BLOB_STORE_URL` | `file://./blobs` | Same store as the gateway. |
| `PAYLOAD_SPILL_BYTES` | `1048576` | Step outputs larger than this are spilled to the blob store. |
| `MAX_CONCURRENT_ACTIVITIES` | `20` | Activities executed concurrently by this process. |
| `EXTERNAL_PLUGINS` | — | Comma-separated external plugins: `wasm:/path/plugin.wasm`, `grpc:http://host:50051`. |
| `LLM_API_KEY` | — | Required for `llm_enricher` / `image_captioner` (the `workers-llm` pool). Without it those plugins register as unavailable. |
| `LLM_BASE_URL` | `https://api.openai.com/v1` | OpenAI-compatible endpoint. |
| `LLM_MODEL` | `gpt-4o-mini` | Default model when a step's `config.model` is absent. |
| `TYPESAFE_API_KEY` | — | Required for `jev_enricher` (the `workers-llm` pool). Without it the plugin registers as unavailable. |
| `TYPESAFE_BASE_URL` | `https://api.typesafe.ai/v1` | TypeSafe API endpoint exposing `/systemone`. |
| `JEV_MODEL` | `jev-latest` | Default Jev model when a step's `config.model` is absent. |
| `TRANSCRIBE_API_KEY` | falls back to `LLM_API_KEY` | Required for `whisper_transcriber` (the `workers-gpu` pool). |
| `TRANSCRIBE_BASE_URL` | falls back to `LLM_BASE_URL`, then `https://api.openai.com/v1` | OpenAI-compatible endpoint exposing `/audio/transcriptions`. |
| `TRANSCRIBE_MODEL` | `whisper-1` | Default transcription model. |
| `INDEXER_TASK_TIMEOUT_SECS` | `120` | How long `meili_indexer` waits for one Meilisearch task before retrying the step; a step's `task_timeout_secs` overrides it. Raise it when Meilisearch is shared with a busy writer (tasks run one at a time), and keep it below the index step's `timeout_secs` (built-in pipelines: 1800). |
| `SOURCE_SECRET_KEY` | — | Same key as the gateway. Opens connection keys in the indexer activity and source credentials in the fetch activity. |
| `MEILI_CONNECTION_HOSTS` | `public` | Same policy as the gateway, re-applied every time a connection is used. |
| `SOURCE_FETCH_HOSTS` | `public` | Same policy as the gateway, re-applied at every fetch and every redirect hop (at most 5) — for scheduled sources and for URL refs in step inputs alike. A refused URL fails the step as non-retryable. `s3://`/`gs://`/`az://` refs are **not** covered (other object-store schemes such as `file://` are refused outright): they are read with the worker's ambient cloud credentials, so scope those to what tenants may read (never the blob store's bucket in a shared deployment). |
| `DEFAULT_INDEX` | `documents` | Index for a source's documents when nothing more specific resolves. Keep it equal to the gateway's. |
| `LAB_EVENTS_ENABLED` | `false` | `true` makes the usage step write one `usage.recorded` and one `job.completed`/`job.failed` event per Lab job to the control plane's outbox. Needs `CONTROL_PLANE_URL` (the worker refuses to start without it). See [Meilisearch Lab](/deployment/meilisearch-lab). |
| `PROVIDER_COSTS_FILE` | bundled `config/provider-costs.toml` | Provider cost table (micro-USD) used to price each job. A call it cannot price costs 0 and marks the job's cost incomplete (the Lab event reports the priced calls' cost and counts the others in `unpriced_provider_calls`). A missing or invalid file stops the worker at boot. |
| `TINYBIRD_TOKEN` | — | Append token for per-tenant [usage analytics](/concepts/usage). Absent disables reporting entirely. |
| `TINYBIRD_BASE_URL` | `https://api.tinybird.co` | Region-specific, e.g. `https://api.eu-central-1.aws.tinybird.co`. |
| `TINYBIRD_DATASOURCE` | `meili_ingest_usage` | Target data source name. |
| `RUST_LOG` | `info` | Tracing filter. |

Workers **never** read `MEILI_URL` / `MEILI_API_KEY`: Meilisearch credentials
arrive in the workflow input as `MeiliContext`.

## Control plane (`meili-ingest-control-plane`)

| Variable | Default | Description |
|---|---|---|
| `DATABASE_URL` | — (required) | Postgres connection string. Migrations run at boot. |
| `BIND` | `0.0.0.0:9000` | Internal listen address. Never expose it publicly: `CONTROL_PLANE_TOKEN` guards `/internal/*` only, and `/pipelines`, `/jobs`, `/plugins` are open. |
| `LAB_URL` | — | Meilisearch Lab base URL (no path or query). Enables the sender that posts Lab events to `{LAB_URL}/internal/events`. Must be `https` unless the host is loopback or private. |
| `LAB_INSTANCE_ID` / `LAB_INSTANCE_SECRET` | — | This deployment's Lab credentials; sign each batch (`X-Lab-Signature` over `"<timestamp>.<body>"`) and answer the workers' credit pre-check of source runs (`GET /internal/lab/credits/{account}`). Required with `LAB_URL`. Credentials of another product's engine abort boot. Never logged. |
| `LAB_EVENTS_SECRET` | — | **Deprecated, and not accepted by a v2 Lab.** The pre-v2 global secret: still read when the instance credentials are unset, but a v2 Lab never acknowledges events signed with it, so they are dropped after 24 h (logged as an error at boot). Set `LAB_INSTANCE_ID` / `LAB_INSTANCE_SECRET` instead. Removed next release. |
| `CONTROL_PLANE_TOKEN` | — (required) | Bearer token callers of `/internal/*` must present (the other routes on this port are not covered). `CONTROL_PLANE_TOKEN_DISABLED=true` runs without it (dev, and step 2 of the [rollout order](/deployment/meilisearch-lab#rollout-order)); a set token is enforced whatever the flag. `CHANGE_ME` is refused at boot. |
| `RUST_LOG` | `info` | Tracing filter. |

## Object store credentials

`BLOB_STORE_URL` schemes other than `file://` use the standard provider
variables read by `object_store`:

| Scheme | Variables |
|---|---|
| `s3://bucket/prefix` | `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_REGION`, optional `AWS_ENDPOINT` (MinIO), or IRSA / instance profile |
| `gs://bucket/prefix` | `GOOGLE_SERVICE_ACCOUNT` / `GOOGLE_APPLICATION_CREDENTIALS`, or Workload Identity |
| `az://container/prefix` | `AZURE_STORAGE_ACCOUNT_NAME`, `AZURE_STORAGE_ACCOUNT_KEY` or SAS / managed identity |

## Temporal Cloud

Point `TEMPORAL_URL` at `https://<namespace>.<account>.tmprl.cloud:7233` and set
`TEMPORAL_NAMESPACE=<namespace>.<account>`. Temporal Cloud requires mTLS (or an
API key); the client certificate and key must be provided to the gateway and
every worker. The exact variable names are those supported by the Temporal
client configuration in `crates/gateway/src/main.rs` and
`crates/worker/src/main.rs` in your build — check them before deploying.

## Where they are set

- **Compose**: inline in `compose.yaml`; secrets via `.env`.
- **Kubernetes**: `ConfigMap meili-ingest-config` in `k8s/control-plane.yaml` and
  `Secret meili-ingest-secrets`, created once outside the kustomization (every key is
  listed in `k8s/secrets.example.yaml`), mounted with `envFrom` / `secretKeyRef`.
  Restart the pods after changing either: env is read at pod start.
